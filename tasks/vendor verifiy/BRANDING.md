## Color Palette

### Primary Colors
- **Navy Blue (Primary):** `#003366`
  - Used for main elements, headers, backgrounds
  - Represents trust, security, professionalism

- **Cyan/Sky Blue (Accent):** `#0066CC` or `#66ccff`
  - Used for highlights, buttons, accents
  - Represents innovation, technology

### Secondary Colors
- **White:** `#FFFFFF`
  - Used for text on dark backgrounds
  - Clean, professional appearance

- **Light Gray:** `#f5f5f5`
  - Background elements
  - Card backgrounds

### Usage
- Primary color (#003366) for navigation bars, headers, main CTAs
- Accent color (#0066CC) for secondary buttons, links, highlights
- Maintain high contrast for accessibility
